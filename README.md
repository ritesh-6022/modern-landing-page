# 🍔 Burger King - Modern Landing Page

A fully responsive modern product landing page built using HTML, CSS, and JavaScript. This project showcases a real-world UI design with mobile responsiveness, modal functionality, and interactive navigation.

---

## 🚀 Live Demo 👉 https://ritesh-6022.github.io/modern-landing-page/

---

## 🔥 Features

- ✅ Fully Responsive Design (Mobile + Tablet + Desktop)
- ✅ Modern UI/UX Layout
- ✅ Mobile Navigation Menu (Hamburger Menu)
- ✅ Overlay Background Effect
- ✅ Login / Signup Modal with Toggle
- ✅ Form Validation (Mobile Number)
- ✅ Smooth Scrolling & Clean Layout
- ✅ Interactive Elements using JavaScript

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (DOM Manipulation)
